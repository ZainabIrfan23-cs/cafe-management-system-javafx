# ☕ Central Perk Café Management System

A JavaFX-based Café Management System developed in Java as a university Object-Oriented Programming project.

## 📌 About the Project

The Central Perk Café Management System is a graphical desktop application designed to manage different aspects of a café, including menu browsing, ordering, cart management, billing, and order history.

The application was developed using Java and JavaFX, applying object-oriented programming concepts to organize the system into different classes and components.

## ✨ Features

- 🔐 Login and user authentication
- 🏠 Dashboard with navigation between application sections
- 🍔 Menu browsing with different food and beverage categories
- 🔎 Menu item search
- 🛒 Cart and order management
- 🧾 Order records and billing
- 📜 Order history
- 💾 File-based data management
- 🖥️ JavaFX graphical user interface

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE configured with JavaFX.
3. Make sure the required JavaFX libraries are configured.
4. Ensure the `images` folder remains in the project directory.
5. Compile and run `centralPerk.java`.
